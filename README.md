# 站点访问管理器

简易的站点地址和端口配置管理工具，使用 Python + PySide6 开发。

## 功能特点

### 站点管理
- ✅ 保存多个站点的地址、端口配置
- ✅ 支持分组管理站点
- ✅ 一键在浏览器中打开站点
- ✅ 支持 HTTP/HTTPS 协议
- ✅ 支持保存用户名和密码（明文存储）
- ✅ 配置自动保存到 JSON 文件
- ✅ 现代化的图形界面设计

### 部署记录（新增）
- ✅ 记录站点部署历史
- ✅ 支持多种部署类型（前端、后端、进程服务、数据库等）
- ✅ 记录部署版本、环境、状态
- ✅ 支持部署人员和备注信息
- ✅ 按时间倒序显示部署记录
- ✅ 状态颜色标识（成功/失败/进行中/回滚）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行程序

```bash
python main.py
```

## 打包成 EXE

### 方法一：使用批处理脚本（推荐）

直接双击运行 `build.bat` 文件，会自动完成打包。

### 方法二：手动打包

```bash
pyinstaller --name="SiteManager" --onefile --windowed --icon=asww.ico --add-data="asww.ico;." main.py
```

打包完成后，可执行文件位于 `dist` 目录下（`SiteManager.exe`）。

## 使用说明

### 站点管理

#### 添加站点

1. 切换到"站点管理"标签页
2. 点击"➕ 添加站点"按钮
3. 填写站点信息：
   - 站点名称：自定义名称，方便识别
   - 地址：IP地址或域名（如 localhost、192.168.1.100）
   - 端口：端口号（如 8080、3000）
   - 协议：选择 http 或 https
   - 路径：可选，API路径（如 /api/v1）
   - 分组：选择或输入新分组名称
   - 用户名：可选，登录用户名
   - 密码：可选，登录密码（输入时显示为密码格式）
4. 点击"保存"

#### 访问站点

- 双击站点列表中的站点
- 或选中站点后点击"🌐 打开站点"按钮

#### 编辑/删除站点

- 选中站点后点击"✏️ 编辑站点"或"🗑️ 删除站点"按钮

#### 分组管理

- 左侧显示所有分组
- 点击分组可筛选显示该分组下的站点
- 点击"全部站点"显示所有站点

### 部署记录（新增）

#### 添加部署记录

1. 切换到"部署记录"标签页
2. 点击"➕ 添加记录"按钮
3. 填写部署信息：
   - 部署类型：前端/后端/进程服务/数据库/其他
   - 站点名称：部署的站点或服务名称
   - 版本号：如 v1.2.3
   - 部署环境：开发/测试/预发布/生产
   - 部署状态：成功/失败/进行中/回滚
   - 部署时间：选择部署时间
   - 部署人员：执行部署的人员
   - 备注：部署说明、变更内容等
4. 点击"保存"

#### 查看部署历史

- 部署记录按时间倒序显示
- 状态使用颜色标识：
  - 🟢 成功：绿色
  - 🔴 失败：红色
  - 🟠 进行中：橙色
  - 🟣 回滚：紫色

#### 删除部署记录

- 选中记录后点击"🗑️ 删除记录"按钮

## 配置文件

### 站点配置
配置保存在程序目录下的 `sites_config.json` 文件中，可以手动编辑或备份。

### 部署记录
部署记录保存在程序目录下的 `deployments.json` 文件中。

## 技术栈

- Python 3.8+
- PySide6 (Qt for Python)
- PyInstaller (打包工具)

## 注意事项

1. 首次运行会在程序目录创建 `sites_config.json` 和 `deployments.json` 配置文件
2. 打包后的 exe 文件可以独立运行，无需安装 Python
3. 配置文件与 exe 文件在同一目录下
4. 建议定期备份配置文件
5. ⚠️ **安全警告**：用户名和密码以明文形式存储在配置文件中，请勿在配置文件中保存敏感账户的凭据
